# One Bit Launcher — сайт для GitHub Pages

1. Создайте репозиторий, например `onebit-site`.
2. Загрузите содержимое этой папки в корень репозитория (index.html должен лежать в корне).
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, папка `/ (root)`.
4. Через минуту сайт откроется по адресу `https://<ник>.github.io/onebit-site/`.

Файл `.nojekyll` оставьте — он отключает обработку Jekyll и сохраняет папки как есть.
Кнопка «Скачать лаунчер» ведёт на `download/OneBitLauncher.exe` внутри репозитория.
